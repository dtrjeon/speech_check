Section 01

앱 개요 및 화면 구성

전도폭발(EE) 훈련생이 복음 제시 대사를 소리 내어 연습하고, 녹음된 음성과 원본 텍스트를 단어 단위로 비교하여 암기 정확도를 점검하는 도구입니다.

화면 구성
사용자 바로그인 이름·반·단계 표시, 로그아웃 버튼
① 챕터 선택암기할 장(章)을 1개 이상 선택
② 원본 텍스트선택된 챕터의 정답 대사 자동 로드
③ 음성 입력STT 또는 텍스트 파일 불러오기로 녹음 텍스트 입력
④ 비교 분석원본과 녹음 텍스트를 단어 단위로 비교
⑤ 결과 패널일치율·누락·추가·대체 단어 색상 표시
💡 우측 상단 🟢 온라인 연결 표시로 인터넷 연결 상태를 확인할 수 있습니다.
우측 하단 🌙 버튼으로 화면 테마를 변경합니다.
Section 02

로그인 · 로그아웃

앱을 열면 로그인 화면이 표시됩니다. 관리자(2단계 교사)에게 발급받은 이름과 비밀번호를 입력해야 사용할 수 있습니다.

  • 이름 입력 후 엔터 → 비밀번호 칸으로 이동합니다.

  • 비밀번호 입력 후 로그인 버튼을 탭하거나 엔터를 누릅니다.

  • 성공하면 상단 사용자 바에 이름 · 반 · 단계가 표시됩니다.

✅ 로그인 정보는 브라우저 세션 동안 유지됩니다. 브라우저를 완전히 닫으면 자동 로그아웃됩니다.
⚠ 비밀번호는 2단계 교사에게 문의해주세요.

로그아웃

상단 사용자 바 오른쪽 로그아웃 버튼을 탭하면 즉시 로그아웃됩니다.

챕터를 선택하면 원본 텍스트 카드에 정답 대사가 자동으로 채워집니다.

카드 조작 버튼
접기/펼치기헤더 오른쪽 버튼으로 텍스트 영역을 숨기거나 표시
전체보기↗ 아이콘 → "챕터 원본" 전체화면 모달로 크게 표시. 모달 상단 가- / 가+ 버튼으로 글자 크기 조절(설정은 기기에 저장되어 다음에도 유지됨)
글자 크기가% 버튼 반복 탭 → 100%~150% 5%씩 증가
✅ 성경 구절([SKIP]...[/SKIP])은 비교 분석 시 자동 제외되며, 삭제된 자리에는 공백 1칸이 유지됩니다.
Section 05

음성 입력 (자동으로 CLOVA · Whisper 사용)

✅ 이 앱은 음성인식 방식을 따로 선택할 필요가 없습니다. Section 03에서 고른 단일/복수 선택에 따라 아래처럼 자동으로 정해집니다.
💡 구두점검 범위에 따라 자동 결정
단일 선택챕터 1개만 점검 → 🤖 Whisper 사용
복수 선택여러 챕터 함께 점검 → 🟢 CLOVA 사용

지금 어떤 방식이 적용됐는지는 📁 업로드 글자 아래 작게 "(Whisper)" 또는 "(CLOVA)"로 표시됩니다.

⚠ CLOVA API, Whisper API는 사용 시간당 비용이 발생합니다. 꼭 필요한 만큼만 녹음·변환해 주세요.
(2단계 교사 비용처리)
📱 기기별 호환성 비교
🤖 갤럭시 🍎 아이폰
🟢 CLOVA ✓ ✓
🤖 Whisper ✓ ✓
📱 텍스트 파일 불러오기 ✓ ✓

CLOVA·Whisper 둘 다 녹음 후 서버로 보내 변환하는 방식이라 갤럭시·아이폰 상관없이 동일하게 사용 가능합니다.

녹음 방법 (공통)

  • 🔒 허용 버튼을 눌러 마이크 접근을 허용합니다.

  • 검은 ● 아이콘을 누르면 녹음이 시작됩니다(빨간색으로 바뀜). 복음 대사를 또렷하게 읽습니다.

  • 읽기가 끝나면 빨간 ● 아이콘을 다시 눌러 녹음을 중지합니다.

  • 자동으로 서버에 전송되어 텍스트로 변환됩니다 (CLOVA는 곧바로, Whisper는 텍스트 추출 버튼을 한 번 더 눌러야 할 수 있습니다).

  • 📥 아이콘을 눌러 녹음(음성+텍스트)을 저장합니다. 저장된 파일은 기기 다운로드 폴더에서 확인할 수 있습니다.

⚠ 인터넷 연결이 필요하며, 변환에 수 초~수십 초가 걸릴 수 있습니다.
Section 06

텍스트 파일 불러오기

📱 이미 다른 방법으로 변환해둔 텍스트를 파일로 불러오거나 직접 붙여넣는 기능입니다.
네이버 클로바노트 앱(무료)으로 녹음·변환하면, 아이폰에서도 이 방법으로 고품질 텍스트를 가져올 수 있습니다.
텍스트 파일 불러오기 방법

  • 클로바노트 등 외부 앱에서 녹음 → 텍스트 변환을 마칩니다.

  • 방법 A (파일) — 공유 → .txt 저장 → 이 앱 → 텍스트 파일 불러오기 탭 → 📂 파일 불러오기 (.txt)

  • 방법 B (복사) — 전체 선택 → 복사 → 이 앱 텍스트 칸에 길게 탭 → 붙여넣기

  • 어느 방법이든 녹음 텍스트로 적용하기 버튼을 누르면 끝입니다.

Section 07

업로드 파일 자동 추출 · STT 오인식 교정

📂 기존 오디오 파일 업로드 → 자동 추출 → 자동 저장

마이크로 직접 녹음하지 않고, 이미 녹음된 오디오 파일(다른 앱으로 녹음한 파일 등)을 올려서 바로 텍스트로 변환할 수도 있습니다.

  • 마이크 녹음 탭 하단 📂 업로드 줄에서 파일 선택을 탭해 오디오 파일을 고릅니다.

  • 파일을 고르면 자동으로 텍스트 추출이 시작됩니다(현재 자동 적용된 방식 사용).

  • 추출이 끝나면 사람이 따로 저장 버튼을 누르지 않아도 텍스트(.txt) 파일이 곧바로 자동 저장(다운로드)됩니다.

💡 "업로드" 글자 아래 작은 글씨로 지금 어떤 방식으로 처리될지 표시됩니다 — "(Whisper)" 또는 "(CLOVA)". 파일을 고르기 전에 미리 확인할 수 있습니다.
✅ 업로드 흐름은 텍스트만 자동 저장됩니다(음성 파일은 자동 저장 안 함). 상태칸이 "✓ 추출+저장 완료"로 바뀌면 정상 처리된 것입니다.
💡 저장되는 파일명 끝에는 어떤 방식으로 추출했는지 표시됩니다 — CLOVA로 추출: _c, Whisper(AI 음성인식)로 추출: _w (예: JUSTEE_녹음_260730_0900_c.txt)

🔤 STT 오인식 자동 교정 사전

음성인식 특성상 "아니오"↔"아니요", "거져"↔"거저"처럼 특정 단어가 반복적으로 잘못 인식되는 경우가 있습니다. 이런 단어들은 비교 분석을 실행하는 순간 자동으로 올바른 표기로 교정된 뒤 비교됩니다.

💡 저장된 .txt 파일 자체에는 교정 전 원문 그대로 저장됩니다. 화면상 비교 분석 결과에만 교정이 적용됩니다.
⚠ 이 교정 사전은 앱 관리자가 관리합니다. 반복적으로 같은 단어가 오류로 잡힌다면 관리자에게 문의해 교정 사전에 추가를 요청하세요.

결과 화면 보는 법

일치율 점수

결과 패널 상단에 % 일치율과 등급이 표시됩니다. 4개 통계 칩으로 전체·일치·누락·추가 단어 수를 확인하세요.

색상 범례

단어일치 — 원본과 정확히 일치
단어누락 — 원본에 있지만 말하지 않음 (취소선)
단어추가 — 원본에 없는데 말한 단어
단어대체 — 비슷하지만 다른 단어

홈화면 설치 (PWA)

앱을 스마트폰 홈화면에 설치하면 일반 앱처럼 아이콘으로 실행할 수 있습니다.

설치하면 홈 화면에 이 아이콘이 생깁니다

⚠ 카카오톡 등 메신저로 받은 링크를 눌러서 열었다면, 그 화면(카카오톡 인앱 브라우저)에서는 홈 화면 추가가 되지 않습니다. 아래 방법으로 먼저 진짜 브라우저(Safari/Chrome/삼성 인터넷)로 옮긴 뒤, 그 다음 카드의 설치 방법을 따라하세요.
💬 카카오톡(인앱 브라우저)에서 열었을 때

  • 카카오톡에서 링크를 눌러 열립니다.

  • 화면 오른쪽 하단(또는 우측 상단) ⋮ 메뉴 버튼을 탭합니다.

  • 메뉴에서 "링크 복사"를 탭합니다. (또는 더 간단하게 "다른 브라우저로 열기"를 탭하면 아래 과정 없이 바로 기본 브라우저로 열립니다.)

  • "링크 복사"를 선택했다면, Safari(아이폰) 또는 Chrome/삼성 인터넷(안드로이드) 앱을 열고 주소창에 붙여넣기 한 뒤 이동합니다.

  • 이제 아래 해당 기기의 카드를 보고 "홈 화면에 추가"를 진행합니다.

⋮ 메뉴를 탭하면 뜨는 화면 — "링크 복사"를 선택하세요

🍎 아이폰 — Safari

  • Safari에서 앱 주소를 엽니다.

  • 하단 가운데 공유 버튼 (□↑)을 탭합니다.

  • "홈 화면에 추가"를 선택합니다.

  • 이름 확인 후 추가를 탭합니다.

🤖 안드로이드 갤럭시 — Chrome

  • Chrome에서 앱 주소를 엽니다.

  • 우측 상단 ⋮ 메뉴를 탭합니다.

  • "홈 화면에 추가" 또는 "앱 설치"를 선택합니다.

  • 추가를 탭합니다.

📱 갤럭시 — 삼성 인터넷(Samsung Internet)

  • 삼성 인터넷 브라우저에서 앱 주소를 엽니다.

  • 하단(또는 상단) ≡ 메뉴 버튼을 탭합니다.

  • "현재 페이지 추가" 탭 → "홈 화면"을 선택합니다.

  • 이름 확인 후 추가를 탭합니다.

💡 갤럭시 기본 브라우저가 Chrome인지 삼성 인터넷인지에 따라 메뉴 위치가 다릅니다. 잘 모르겠으면 아이콘 모양으로 구분하세요 — 두 방법 중 맞는 쪽을 따라하시면 됩니다.
Section 14

자주 묻는 질문 (FAQ)

Q. 아이폰에서 녹음이 안 됩니다

이 앱은 아이폰에서도 문제없이 작동합니다 — CLOVA·Whisper는 iOS 제한과 무관하게 자동으로 사용됩니다. 그래도 안 되면 텍스트 파일 불러오기 탭을 이용하세요.

Q. 비밀번호를 모릅니다

2단계 교사(관리자)에게 문의하세요. 관리자는 Google Sheets user_list 시트에서 직접 변경할 수 있습니다.

Q. 여러 챕터를 한 번에 점검하려면?

상단에서 "복수 선택" 모드로 바꾼 뒤 챕터 카드를 순서대로 탭하세요. 선택한 순서대로 원본 텍스트가 이어집니다.

Q. 성경 구절이 틀렸다고 표시됩니다

앱 원본 텍스트의 성경 구절은 [SKIP] 태그로 자동 제외됩니다. 직접 입력한 텍스트에는 동일하게 태그를 추가하거나 해당 구절을 삭제하세요.

Q. 분석 결과를 파일로 저장하려면?

프린트 출력 시 브라우저 인쇄 대화상자에서 "PDF로 저장"을 선택하면 됩니다.

Q. 암기개요 설정이 초기화됩니다

암기개요 변경 후 반드시 저장 버튼을 눌러야 브라우저에 보존됩니다.

Q. 오디오 파일을 업로드했는데 텍스트가 저장이 안 됩니다

업로드 흐름은 추출이 끝나면 자동으로 텍스트(.txt)가 저장됩니다. 상태칸이 "✓ 추출+저장 완료"로 바뀌는지 확인하세요. 계속 "추출 중..."에 머문다면 인터넷 연결을 확인하고 다시 시도해 주세요.

Q. 화면을 확대(핀치줌)하면 글자가 화면 밖으로 잘려서 안 보입니다

손가락으로 화면 전체를 확대하는 대신, "챕터 원본" 전체보기 모달 안의 가- / 가+ 버튼을 사용하세요. 박스 폭은 그대로 유지한 채 글자만 커져서 줄바꿈이 유지됩니다.

전체 사용 흐름

  • 로그인 (이름 + 비밀번호)
  • 챕터 선택 (1개 이상)
  • 원본 텍스트 확인 (자동 로드)
  • 구두점검 범위 선택 (단일/복수 → Whisper/CLOVA 자동 결정) 또는 텍스트 파일 불러오기
  • 복음 대사 낭독 및 텍스트 저장
  • 비교 분석 버튼 실행
  • 색상 강조로 오류 확인
  • (필요 시) 미리보기 · 프린트 출력
  • 사용 종료 시 로그아웃
